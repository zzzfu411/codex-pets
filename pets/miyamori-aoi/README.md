# 宫森葵·喵森

以动漫《白箱》的宫森葵为参考创作的 Q 版 Codex 宠物。焦糖短发、蓝色工作外套、黑色背带裙与手中的甜甜圈，搭配认真又元气的表情。

![宫森葵·喵森待机预览](preview.gif)

[下载宠物安装包](../../downloads/miyamori-aoi.zip)

解压后，将 `miyamori-aoi` 文件夹放入 `~/.codex/pets/`。如果设置了 `CODEX_HOME`，则放入其中的 `pets/`。在应用的宠物设置中刷新并选择「宫森葵·喵森」。

`pet.json` 和 `spritesheet.webp` 必须放在同一个文件夹中。宠物采用 Codex v2 图集：1536 × 2288 像素，单帧 192 × 208 像素，包含 9 组状态动作与 16 个视线方向。

成品已完成图集、透明边缘、动作循环与独立方向验收。部分接近水平的斜向视线变化较轻，保留自然的头颈转动。
